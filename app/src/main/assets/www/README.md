# Multi Clone — UI Prototype

Blue-and-white English UI prototype designed for phone-first editing in SPCK Editor.

## Files
- `index.html` — app shell and bottom navigation
- `css/style.css` — responsive visual design
- `js/app.js` — demo-only navigation, sample app list, sample clone list, dialogs and mock clone entries

## Run in SPCK Editor
1. Create/open a folder named `MultiCloneApp_UI`.
2. Create the files and folders exactly as listed above.
3. Paste the matching code into each file.
4. Open `index.html` with SPCK preview.

## Important
This is only a front-end UI prototype. It does not read installed Android apps, create real app instances, isolate app data, or launch other applications. The app list, storage figures and clones are mock data. Actual cloning would require a separate native Android virtualization investigation and compatibility/security testing.
